About This App

🔍 The Problem

Small scrum teams within larger organisations often lack a simple way to track holidays at team level. Company-wide tools like Workday operate at a broader organisational level and don't give a scrum team instant visibility of who is off and when. As a workaround, teams resort to manually maintaining a shared list in a Slack tab — which is error prone, hard to read, and gives no visual indication of overlaps that could impact sprint planning and day to day collaboration.

💡 The Solution

Team Holiday Tracker is a lightweight internal web app built specifically for a small scrum team. It gives the team a shared calendar view of all holidays, automatically highlights days where multiple people are off simultaneously, and integrates with Slack to keep the team informed without any extra effort. Bank holidays for UK, Romania and India are displayed automatically so the team always has full context when planning. No installation required — just a browser and a link.

✨ Key Features

  • Calendar view with colour coded holidays per person
  • Overlap detection with red indicator and summary banner
  • Bank holidays for 🇬🇧 UK, 🇷🇴 Romania and 🇮🇳 India shown automatically
  • Slack notifications on holiday addition and weekly Monday summary
  • Team management — add or remove members via the settings tab
  • Data persistence — holidays survive app restarts
  • No individual logins required

🛠 Tech Stack

  • Backend: ASP.NET Core 8 (C#)
  • Database: SQLite via Entity Framework Core
  • Frontend: Vanilla HTML, CSS and JavaScript
  • Notifications: Slack Incoming Webhooks
  • Bank Holidays: Nager.Date API and hardcoded Indian holidays
  • Testing: MSTest — 33 unit tests
  • Hosting: Railway (Docker)
  • Source Control: GitHub (private)

🚀 Planned Next Steps

  • Migrate to Azure App Service and Azure SQL
  • Add individual logins with role based access
  • Secure secrets via Azure Key Vault
  • Persistent shared database to replace SQLite
  • Jira integration - Connect holidays directly to Jira and make capacity and velocity adjustments, show impact and warnings
